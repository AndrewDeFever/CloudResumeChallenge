# Security Policy

## Supported Version

This repository supports the current production version of the Cloud Resume project as represented by the default branch (`main`).

Historical commits, archived artifacts, and superseded implementations are not maintained as supported versions.

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately through GitHub's **Private vulnerability reporting** feature for this repository.

Do **not** open a public GitHub issue for a security vulnerability or include secrets, credentials, exploit details, or sensitive data in a public discussion.

When reporting an issue, include enough information to reproduce and assess it, such as:

- the affected file, component, endpoint, or workflow;
- a clear description of the behavior and potential impact;
- reproduction steps or a minimal proof of concept;
- relevant logs, screenshots, or request/response details with secrets and personal data removed;
- any suggested remediation, if known.

Reports will be reviewed and prioritized based on severity, exploitability, and impact.

## Scope

Security reports related to this repository, its deployment workflows, and the publicly deployed Cloud Resume application are in scope.

Issues that are purely functional, cosmetic, accessibility-related, or feature requests should be reported through normal GitHub issues rather than the private vulnerability-reporting channel.

## Sensitive Information

If you discover an exposed credential or secret, report it privately and do not test it beyond what is necessary to confirm the exposure. Potentially exposed credentials will be revoked or rotated as appropriate before any repository-history cleanup is considered.
