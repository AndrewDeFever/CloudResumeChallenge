About This Site

Built for the Cloud Resume Challenge to demonstrate cloud deployment, automation, security hardening, and a small serverless app.

Frontend & DNS

  • Static site assets are stored in a private Amazon S3 bucket and delivered globally through CloudFront over HTTPS.
  • Route 53 provides public DNS and ACM manages the TLS certificate used by CloudFront.
  • The S3 origin blocks public access and is reachable through a CloudFront Origin Access Control (OAC).
  • Deploys apply asset-specific Cache-Control metadata and targeted CloudFront invalidations for predictable cache behavior.

Serverless Backend

  • API Gateway HTTP APIs → Lambda (Python) → DynamoDB handles visit tracking and geolocation data.
  • API stages use request throttling and CORS restricted to the resume origin; Lambda invoke permissions are scoped to the required API routes.
  • CloudWatch Logs provides operational visibility with managed log retention.

CI/CD & Security

  • GitHub Actions uses OIDC to obtain short-lived AWS credentials without storing long-lived access keys.
  • The application stack is managed with CloudFormation; infrastructure changes are reviewed through change sets before execution instead of auto-deploying production infrastructure.
  • Least-privilege IAM, dedicated Lambda runtime roles, private S3 origin access, HTTPS enforcement, and CloudFront security response headers reduce the public attack surface.

UI Features

  • Interactive visitor map using Leaflet with clustering and heat overlay.
  • Recent visitor list with country flags and ISP icons; total visit count.
